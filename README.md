# Códice móvil

Lector y editor rápido de libros de rol hechos con Códice, para usar en la mesa de juego.

Ábrelo en https://hiyedev.github.io/codice/ y añádelo a la pantalla de inicio:

- Android (Chrome): menú ⋮ → Instalar aplicación.
- iPhone (Safari): Compartir → Añadir a pantalla de inicio.

Funciona sin conexión. Los libros que abras o edites se guardan solo en tu móvil.
